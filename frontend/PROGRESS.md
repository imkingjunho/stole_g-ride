## 실행

```powershell
cd frontend
npm.cmd ci
npm.cmd run dev
```

기본은 mock 모드. `/login`의 **목 데이터로 둘러보기** → **DEV · 기능 체험**으로 성사·수락·채팅·정산을 확인한다. 요청·대기 화면은 팀원 담당 placeholder 그대로다. `frontend/.env.local`에서 `VITE_API_MODE=real`과 `VITE_API_BASE_URL`을 설정하면 동일 화면이 실제 서버를 요청한다. JWT API가 없는 현 main 서버와는 완전한 로그인 흐름을 검증할 수 없다. 모드 변경 후 Vite 재시작이 필요하다.

- `npm run gen:api`: 명세에서 타입 재생성. 수동 수정 없음.
- `npm run lint`와 `npm run build`.
- `scripts/verify-ui.mjs`: Playwright가 설치된 검사 환경에서 실행. 선택적으로 `CHROMIUM_PATH`, `QA_OUTPUT` 지정. 기본 결과 폴더 `qa-output`.
- `scripts/verify-real-transport.mjs`: real 모드에서 MSW 없이 로컬 HTTP 테스트 서버로 요청·동시 401 갱신·Bearer 재시도 확인. 팀 백엔드 통합 검사가 아니다.
