- 성사 화면의 지도 준비 영역을 송준호 `RouteMap`과 연결했다. `route.sections[].path`와 거점, 하차 순서로 정렬한 목적지 좌표·닉네임을 전달한다.

- 프로필 수정 응답을 조회 캐시와 로그인 사용자 정보에 반영한다.
- 로그인·가입·갱신·프로필·로그아웃의 요청/응답을 현재 main의 Java DTO 및 OpenAPI와 대조했다. 실제 데이터베이스·메일·JWT 서버와의 통합 성공을 뜻하지 않는다.

## 실행과 실제 서버 확인

`frontend/.env.local`에 아래를 설정한 뒤 Vite를 재시작한다. JavaScript 키는 본인 카카오 앱에서 발급한 값을 사용한다.

```dotenv
VITE_API_MODE=real
VITE_API_BASE_URL=http://localhost:8080
VITE_KAKAO_JS_KEY=본인_카카오_JavaScript_키
```

서버 CORS와 카카오 허용 도메인에 맞춰 `http://localhost:5173`으로 접속한다. 실제 가입 → 메일 코드 → 프로필 등록 → 로그인 → 내 정보 수정 → 새로고침 → 로그아웃 순서로 확인한다. API 서버, MySQL·Redis·메일 설정은 백엔드 담당 환경을 사용한다. mock 모드에서는 외부 서버 없이 `/login` → 목 데이터로 둘러보기 → DEV 기능 체험으로 지도 연결을 포함한 화면을 확인할 수 있다. 지도 키가 없으면 지도 컴포넌트가 오류 안내를 표시하며 나머지 화면은 계속 동작한다.
