# 가치가 베타 사용 경험 설문

이 설문은 실제로 사용한 흐름의 개선점을 확인하기 위한 것입니다. 이름·연락처·이메일·비밀번호는 적지 않습니다.
목 체험이면 MOCK, 실제 서버를 이용한 베타이면 REAL로 구분합니다.

- 참여자 번호: P___
- 사용 구분: REAL / MOCK
- 사용 날짜: YYYY-MM-DD
- 경험하지 못한 문항: 빈칸으로 둡니다.

점수: 1 매우 그렇지 않다 / 2 그렇지 않다 / 3 보통이다 / 4 그렇다 / 5 매우 그렇다

| 항목 | 문항 | 점수 |
|---|---|---|
| request_ease | 출발 거점·목적지·요청 조건을 쉽게 입력할 수 있었습니다. | |
| fare_clarity | 혼자 갈 때와 동승할 때의 요금 차이 및 분담 이유를 이해할 수 있었습니다. | |
| chat_ease | 채팅과 빠른 메시지로 동승자와 소통하기 쉬웠습니다. | |
| error_recovery | 오류나 연결 끊김이 발생했을 때 다음에 무엇을 해야 할지 알 수 있었습니다. | |
| overall_satisfaction | 전반적인 서비스 이용 경험에 만족합니다. | |

선택 의견: 가장 불편했던 점 또는 개선하면 좋을 점을 적어 주세요.

전체 만족도 지표는 overall_satisfaction의 유효한 실제 응답만 사용합니다.
