# 가치가 — Stitch 디자인을 반영한 독립 화면 시안

전남대학교 동승 프로젝트의 프론트엔드 시안입니다. 사용자가 제공한 `stitch_taxi_dispatch_app_design.zip`을 기준으로 기존 `frontend/prototype`의 화면과 스타일을 교체했습니다. React 18, TypeScript, Vite, Tailwind CSS를 사용합니다.

실제 인증·지도·서버 연결을 추가하지 않고 기존의 독립적인 화면 미리보기를 유지합니다.

## 화면 바로 보기

빌드된 `WE-Meet-Preview.html`을 내려받아 브라우저로 열면 됩니다. 설치나 인터넷 연결 없이 동작합니다.

- 오른쪽 위 메뉴: 로그인·회원가입을 포함한 모든 화면 이동
- 하단 메뉴: 동승·채팅·이력·내 정보 이동
- 오른쪽 위 메뉴의 **화면 상태**: 로딩·오류·빈 화면 확인
- 넓은 화면에서도 최대 440px의 모바일 화면을 가운데 표시

## VS Code에서 실행

Node.js 24 환경에서 저장소 루트 기준으로 실행합니다. Windows PowerShell에서는 `npm.cmd`를 사용합니다.

```powershell
cd frontend/prototype
npm.cmd ci
npm.cmd run dev
```

터미널에 표시되는 `http://127.0.0.1:5173/`을 엽니다. 개발 서버가 실행 중인 터미널은 유지하고, 추가 명령은 새 터미널에서 입력합니다. 압축을 푼 `prototype` 폴더 자체를 VS Code로 열었다면 첫 번째 명령은 생략합니다. macOS/Linux에서는 `npm.cmd` 대신 `npm`을 사용합니다.

검사와 빌드:

```powershell
npm.cmd run lint
npm.cmd run format:check
npm.cmd run build
```

`dist/WE-Meet-Preview.html`은 CSS와 JavaScript가 모두 포함된 단일 파일입니다. `node_modules`와 `dist`는 Git에 올리지 않습니다.

## 디자인 반영 범위

첨부 ZIP의 `toss_mobility_campus_transit/DESIGN.md`와 파란색 최종 화면을 기준으로 작업했습니다.

| 기존 화면   | 첨부 디자인 기준 | 반영 내용                                                       |
| ----------- | ---------------- | --------------------------------------------------------------- |
| 로그인·가입 | `_12`            | 캠퍼스 배지, 파란 택시 아이콘, 학교 이메일 입력, 흰색 안내 카드 |
| 매칭 성사   | `_1`             | 예상 분담액 강조, 절감액, 출발·하차 순서, 동승자 카드           |
| 정산 상세   | `_8`             | 구간 막대, 구간별 카드, 사람별 합계, 공정 분담 안내             |
| 채팅        | `_10`            | 안내 상자, 좌우 말풍선, 빠른 문장, 둥근 입력창                  |
| 이용 이력   | `_11`            | 절감액 요약, 기간 필터, 동승 내역 카드                          |
| 내 정보     | `_7`             | 프로필 카드, 어두운 누적 절감액 카드, 메뉴 목록                 |

기존 데스크톱 사이드바와 초록색 중심 테마를 제거했습니다. 화면 여백 20px, 흰색 카드, 회색 배경, 파란색 주요 동작, 초록색 절감액, 고정 하단 메뉴를 사용합니다. 아이콘은 로컬 SVG이며, 글꼴은 설치된 Pretendard 또는 시스템 한글 글꼴을 사용하므로 첨부 이미지와 글꼴 모양에 약간 차이가 날 수 있습니다. 외부 폰트·아이콘 CDN을 호출하지 않습니다.

첨부 이미지의 요청·대기 화면은 다른 담당자의 범위이므로 추가하지 않았습니다. 하단 메뉴는 현재 구현된 화면에 맞춰 동승·채팅·이력·내 정보로 연결했습니다.

## 확인할 수 있는 동작

- 로그인, 이메일 → 인증번호 → 프로필의 화면 이동과 기본 입력 형식 검사
- 비밀번호 보기·숨기기, 성별 선택, 선택 항목 펼치기
- 동승 완료 안내 팝업, 완료 화면과 되돌리기
- 구간별 분담액, 100원 단위 보정 설명 팝업
- 채팅 문장 미리보기, 빠른 문장 선택, 500자 제한, 한글 조합 Enter 처리
- 고정된 9월 예시 이력의 기간 필터와 상세 보기, 8월 빈 내역
- 프로필·서비스 안내와 공통 로딩·오류·빈 화면

정산은 PRD §5.2의 고정 예시를 유지합니다. 100원 단위 보정 후 **1,500 + 3,800 + 9,700 = 15,000원**입니다. 내 분담액은 3,750원에서 3,800원으로 보정됩니다. 이력과 프로필의 누적 절감액 14,200원은 같은 예시 이력 3건에서 표시합니다.

## 서버 연결 범위

현재 시안에는 HTTP 호출, WebSocket, 토큰 저장, 실제 계정 생성, 실제 정산 계산·결제가 없습니다. 입력 내용은 전송·영구 저장하지 않습니다. 채팅 말풍선은 현재 탭에만 표시되며 새로고침하면 초기화됩니다. 로그인과 가입에는 미리보기용 임의의 값을 사용하세요.

팀원이 제공한 API 계약과 지도 경로 응답은 향후 실제 연동 작업의 기준입니다. 현재 고정 예시 객체를 서버 DTO로 사용하지 않습니다. 이번 변경은 디자인 교체에 한정하며 Phase 1 연동 완료를 뜻하지 않습니다.

## 코드 위치와 교체 범위

```text
frontend/prototype/
  src/app/App.tsx                       모바일 레이아웃·메뉴·라우트
  src/shared/ui/                        공통 UI·SVG 아이콘
  src/shared/preview/                   고정 예시·화면 상태
  src/features/auth/AuthPage.tsx        로그인·가입
  src/features/group/GroupPage.tsx      성사·정산
  src/features/chat/ChatPage.tsx        채팅 시안
  src/features/history/HistoryPage.tsx  이력·내 정보
  src/styles.css                       새 디자인 스타일
```

교체 대상은 **`frontend/prototype`뿐**입니다. 팀의 `frontend` 전체, 요청·지도 담당 폴더, 백엔드, 공용 문서를 삭제하거나 덮어쓰지 않습니다. 단일 HTML 실행을 위해 해시 라우트(`#/login` 등)를 유지합니다.

검증 결과는 `VERIFICATION.md`를 참고하세요.
