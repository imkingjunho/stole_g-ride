> 이 파일은 AI 코딩 어시스턴트가 읽는 작업 지시서다. 완료한 항목은 `[x]`로 바꾼다. AI는 **가장 위의 미완료 항목**부터 진행한다.
> 근거 문서는 `docs/PRD.md`. 특히 §4.1·§4.5(FR), §7(users·refresh_tokens·reports·chat_messages), §12.3-③, §14.5(WebSocket 프로토콜)를 따른다.
> Phase 1 이후 항목은 이승민의 "Phase 0 끝" 공지 뒤에 시작한다.

## 내 파트 한 줄

**계정**(웹메일 인증·JWT·프로필·신고)과 **실시간**(WebSocket 전부 — 인증 핸드셰이크, 대기 상태 push, 매칭 알림 push, 채팅). WebSocket을 한 사람이 다 갖는 이유는 STOMP 설정 파일이 두 사람에게 걸치면 충돌 1순위가 되기 때문이다. Security 설정도 `config/`가 아니라 내 `auth/`에 있다 — 인증 필터를 등록하는 사람이 설정 파일도 가진다.

## 내 폴더 (여기만 수정한다)

```
backend/src/main/java/com/gachiga/
├── auth/         SecurityFilterChain, JWT 발급·검증·필터, 웹메일 인증, Refresh 회전, @CurrentUser 리졸버
├── user/         User 엔티티, 프로필 API, 신고·이용 제한, UserPort 구현
└── realtime/     WebSocketConfig(STOMP), CONNECT 인증 인터셉터, 구독 인가, 대기 상태 push, 매칭 알림 push,
                  chat/ (ChatMessage 엔티티, 송수신, 자동 개설, 물리 삭제 스케줄러, 퀵 메시지, 마스킹)
backend/src/main/resources/domain/auth.yml       (gachiga.auth.*, spring.mail.*, gachiga.chat.*)
backend/src/test/java/com/gachiga/{auth,user,realtime}/
```

## 담당 FR

**FR-01**(웹메일 가입), **FR-02**(JWT), **FR-03**(프로필), FR-04(신고, P2), FR-09(대기 상태 **push**, P1), **FR-12**(그룹 확정 **알림 push**), **FR-20**(채팅방), **FR-21**(휘발성), FR-22(퀵 메시지, P1), FR-23(마스킹, P1), E-05, E-09(서버 측), E-10

## 계약 (PRD §14)

| 내가 **구현**하는 것 | 내가 **쓰는** 것 |
|---|---|
| `UserPort` (서준·이승민이 사용) | `QueueStatusPort` (이승민) — 5초마다 대기 상태 조회 후 push |
| `@CurrentUser` 리졸버 (전원의 컨트롤러가 사용) | `MatchHistoryPort` (서준) — 채팅 구독 인가, 신고 검증 |
| WebSocket 프로토콜 §14.5 전체 (오승원·송준호 프론트가 사용) | 이벤트 수신: `RideRequest*`(대기 화면 갱신), `Group*`(알림 push·채팅방 개설·삭제 예약) |

**`.env.example` 항목이 필요하면**(`JWT_SECRET`, `MAIL_HOST`, `MAIL_USERNAME`, `MAIL_PASSWORD`) 직접 고치지 말고 단톡방에 `[.env 항목 요청]`. 값은 내 `.env`에만.

## 이 파트만으로 보여줄 수 있는 것

가입 → 메일 코드 → 로그인 → JWT로 `/api/users/me`. STOMP 클라이언트 2개를 붙여 채팅 왕복. `MatchHistoryPort` 스텁이 항상 true를 주므로 서준의 그룹이 없어도 채팅은 시연된다.

## 포트폴리오 포인트

> "JWT Refresh 토큰 회전 방식의 인증 체계를 설계하고, 학교 웹메일 인증으로 폐쇄형 커뮤니티를 구현. STOMP CONNECT 단계에서 JWT를 검증하고 구독 시점에 그룹 멤버십을 인가해, 인증과 실시간 통신을 하나의 모듈로 통합."

- 왜 HTTP 필터가 아니라 `ChannelInterceptor`로 WebSocket을 인증하는가
- 왜 WebSocket 전체를 한 모듈에 모았는가 (설정 파일 충돌 방지 → 협업 구조 설계)
- Refresh 회전이 막는 공격 시나리오
