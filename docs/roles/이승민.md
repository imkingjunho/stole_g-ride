> 이 파일은 AI 코딩 어시스턴트가 읽는 작업 지시서다. 완료한 항목은 `[x]`로 바꾼다. AI는 **가장 위의 미완료 항목**부터 진행한다.
> 근거 문서는 `docs/PRD.md`. 특히 §9(구조), §12.3-①(내 파트), §14(계약), §15.2(Phase 0)를 따른다.

## 내 파트 한 줄

팀 전체가 올라탈 **뼈대·계약·스텁·CI**를 Phase 0에 만들고, 그 뒤 **매칭 요청·대기열·만료** 모듈을 구현하며, 마지막에 **통합·성능·배포**를 맡는다. 이 파트의 절반은 "남이 막히지 않게 하는 일"이다.

## 내 폴더 (여기만 수정한다)

```
backend/src/main/java/com/gachiga/
├── GachigaApplication.java
├── common/        공통 응답·예외·에러 코드·유틸·ArchitectureTest
├── config/        Jackson, Redis, Swagger, CORS, 스케줄링
├── contract/      ⚠️ 동결 계약 (PRD §14) — 나만 수정, 요청 받아서
└── ride/          RideRequest, 요청 API, Redis 대기열, 만료 스케줄러, RideRequestPort·QueueStatusPort 구현
backend/src/main/resources/application*.yml, domain/ride.yml
backend/src/test/java/com/gachiga/{common,config,ride}/
backend/build.gradle, backend/settings.gradle
docker-compose.yml, .env.example, .gitignore, .github/**
docs/PRD.md, docs/api-spec.yaml, docs/traffic-analysis.md, README.md, CLAUDE.md
```

**Phase 0 한정 예외:** `frontend/` 초기 스캐폴드와 다른 사람 폴더의 스텁 파일은 Phase 0에 내가 만든다. Phase 0 종료 공지 이후에는 그 폴더들을 건드리지 않는다.

## 담당 FR

FR-07(요청 필드), **FR-08**(대기열 등록/취소), FR-09(대기 상태 데이터 — `QueueStatusPort`), **FR-10**(만료 처리), E-02(낙관적 락), E-04(만료 30초 전 제외), E-08(최소 500m)

## 계약 (PRD §14)

| 내가 **구현**하는 것 | 내가 **쓰는** 것 |
|---|---|
| `RideRequestPort` (서준이 사용) | `RouteProvider`, `HubPort` (송준호) — 단독 거리·요금 캐시, 거점 검증 |
| `QueueStatusPort` (임승현이 사용) | `UserPort` (임승현) — 이용 제한 사용자 요청 차단 |
| 이벤트 발행: `RideRequestCreated / Cancelled / Expired` | 이벤트 수신: `GroupConfirmed / Dissolved / Completed` → 요청 상태 정리 |
| `common/`·`contract/` 전체 (전원이 사용) | |
