# 추천 만남 지점 운영 메모

2026-11-18 사용자 피드백 반영. 화면의 안내는 모이는 장소 추천이며, 지정 택시 승차구역이나 실측 핀을 뜻하지 않는다. 상호·도로 좌우·출구를 확인 없이 만들어 넣지 않는다. 참가자들은 현장 표지와 채팅으로 같은 지점을 확인한다.

- 전남대 정문: 정문 바깥 입구 옆 보행 공간. 현장 확인 전 특정 가게나 좌우 방향을 고정하지 않는다.
- 전남대 후문: 후문 정류장 주변 보행 공간. 도로 양쪽 정류장을 혼동하지 않도록 정류장 이름과 도로 방향을 채팅에서 확인한다. [전남대 캠퍼스 안내](https://cloudweb.jnu.ac.kr/bbs/korcc/781/817788/download.do)에 후문 정류소가 기재되어 있다.
- 예대 삼거리: 예술대학 진입 방향 보행 공간. 정확한 모퉁이는 현장 확인 대상.
- 경신여고: 정문 바깥 보행 공간. 차도·진입로를 피한다.
- 유스퀘어: 현장 택시승강장 안내 표지 주변에서 대기 줄 진입 전 먼저 만난다. 출구 번호·가게명은 현장 확인 전 넣지 않는다.
- 광주송정역: 지하철 2번 출구 앞 전용승차대 주변. [광산구 공식 2026년 4월 안내](https://www.gwangsan.go.kr/upload/bb/GUBO/1774921008106.pdf)는 2번 출구 앞 전용승차대와 3번 출구 앞 하차구역을 구분한다. 현장 표지가 달라지면 운영팀이 갱신한다.

운영팀이 직접 찍은 표지·사진·좌표를 확보하면 해당 추천 문구를 확정 안내로 교체한다. 현재 지도 핀은 기존 거점 좌표를 유지한다.
